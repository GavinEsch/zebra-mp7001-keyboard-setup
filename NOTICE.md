# Third-party documentation

`Scanner-Programming-Barcodes.pdf` contains two selected pages from Zebra Technologies' **MP7000 Scanner Scale Barcode Programming Guide**, **MN-002912-12EN**, Revision A, April 2025:

- Original PDF page 32 / printed page 2-9: Symbol Native API (SNAPI) with Imaging Interface.
- Original PDF page 342 / printed page 6-95: Data As Is, parameter 235 = 0.

The printed page content and barcode artwork are unchanged. PDF navigation links and article-thread references were excluded when creating the two-page excerpt.

Source: [Zebra's official programming guide](https://www.zebra.com/content/dam/support-dam/en/documentation/unrestricted/guide/product/mp7x00-prg-en.pdf).
